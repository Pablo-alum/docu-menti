| Tipo       | Cuándo usar                   | Ejemplo para tu proyecto                                                 |
| ---------- | ----------------------------- | ------------------------------------------------------------------------ |
| `feat`     | Nueva feature                 | `feat(ocr): agregar detección de duplicados por SimHash`                 |
| `fix`      | Corrección de bug             | `fix(auth): resolver null pointer en validación de JWT expirado`         |
| `docs`     | Documentación                 | `docs(readme): agregar instrucciones de deploy con Docker`               |
| `style`    | Formato, sin cambio de lógica | `style(domain): aplicar formato consistente en entidades`                |
| `refactor` | Reestructuración de código    | `refactor(api): extraer validación de subida a servicio separado`        |
| `perf`     | Mejora de performance         | `perf(search): agregar índice GIN para búsqueda full-text`               |
| `test`     | Tests                         | `test(subida): agregar tests para detección de imágenes no documentales` |
| `chore`    | Tareas de mantenimiento       | `chore(deps): actualizar Spring Boot a 3.3.0`                            |
| `ci`       | CI/CD                         | `ci(github): agregar workflow de benchmark con k6`                       |
| `revert`   | Revertir commit               | `revert(feat): revertir caché de categorías por inconsistencia`          |

| Scope            | Qué cubre                                            |
| ---------------- | ---------------------------------------------------- |
| `domain`         | Entidades, value objects, excepciones de negocio     |
| `application`    | DTOs, mappers, casos de uso, eventos                 |
| `infrastructure` | Repositorios JPA, MinIO, Redis, Tesseract, seguridad |
| `api`            | Controllers, validators, exception handlers          |
| `ocr`            | Pipeline de OCR, Tesseract, clasificación            |
| `auth`           | JWT, roles, login, registro                          |
| `search`         | Búsqueda full-text, índices, queries                 |
| `dashboard`      | Métricas, KPIs, endpoints de estadísticas            |
| `benchmark`      | Tests de carga, panel de rendimiento                 |
| `frontend`       | Componentes Vue, vistas Astro, stores                |
| `infra`          | Docker, nginx, CI/CD, scripts                        |
| `docs`           | README, ADRs, guías                                  |
